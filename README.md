# Oasis-Infobyte-Internship

# 🚀 Oasis Infobyte Data Analytics Internship Projects
This repository contains the Data Analytics and Machine Learning projects completed during my internship at Oasis Infobyte. The internship focused on developing practical skills in data analysis, visualization, preprocessing, and machine learning using Python and Jupyter Notebook. The internship required successful completion of multiple tasks from Level 1 and Level 2 projects.


# 📌 Projects Included

## 📊 Task 1: Exploratory Data Analysis (EDA) on Retail Sales Data
Performed Exploratory Data Analysis on retail sales data to uncover sales trends, customer behavior, and business insights for better decision-making.

### 🔹 Key Features
* Data Cleaning & Preprocessing
* Descriptive Statistics
* Time Series Analysis
* Customer & Product Analysis
* Data Visualization using Charts & Heatmaps
* Business Insights & Recommendations


## 🧹 Task 2: Cleaning Data 
Worked on cleaning and preprocessing raw datasets by handling missing values, duplicates, inconsistencies, and outliers to improve data quality.

### 🔹 Key Features
* Missing Value Handling
* Duplicate Removal
* Data Standardization
* Outlier Detection & Removal
* Data Integrity Checks
* Data Visualization


## 🍷 Task 3: Wine Quality Prediction
Built Machine Learning classification models to predict wine quality based on chemical properties such as acidity, density, alcohol content, and pH levels.

### 🔹 Key Features
* Data Cleaning & Exploration
* Feature Selection & Scaling
* Random Forest Classifier
* SGD Classifier
* Support Vector Classifier (SVC)
* Accuracy Comparison & Evaluation
* Heatmaps & Visualization


## 📱 Task 4: Google Play Store Data Analysis
Analyzed Google Play Store data to understand app market trends, user preferences, ratings, installs, and pricing patterns.

### 🔹 Key Features
* Data Cleaning & Preprocessing
* Category Exploration
* Ratings & Install Analysis
* Price & Size Analysis
* Correlation Heatmaps
* Interactive Visualizations
* Market Trend Insights
